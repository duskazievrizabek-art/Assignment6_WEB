# Assignment #6: jQuery (Selectors, Effects, Animations)

## Overview
This project demonstrates DOM manipulation, event handling, jQuery effects, custom animations, and an interactive accordion menu.

## Navigation & Structure
- `part1.html` - Task 0 & Task 1 (CDN setup, console check, selectors, .text(), .html(), .css())
- `part2.html` - Tasks 2-4 (Visibility, Fade, Slide methods)
- `part3.html` - Tasks 5-7 (DOM Manipulation, Attribute modification, Live Form interaction)
- `part4.html` - Tasks 8-10 (Basic, Sequential, and Combined animations)
- `part5.html` - Task 11 (Interactive Accordion Menu)

## How to Run
Open `part1.html` in any web browser and use the navigation bar to move between tasks.
